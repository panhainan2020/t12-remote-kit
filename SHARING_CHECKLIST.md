# Sharing checklist

- [ ] Keep the no-license notice visible until the owner deliberately selects a license.
- [ ] Share only this kit, not the full VITAL_Lab-Omni history.
- [ ] Do not commit `config/t12_serial.local.yaml` or mapping-report JSON files.
- [ ] Replace udev VID/PID placeholders locally; do not publish unique receiver serials.
- [ ] Run the unit tests on the recipient's Python environment.
- [ ] Perform read-only monitoring before integrating commands.
- [ ] Verify failsafe and zero-command behavior with actuators disabled.
- [ ] Document the exact adapter frame format and baud rate for each hardware set.
